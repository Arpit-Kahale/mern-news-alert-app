# 📰 NewsPulse AI Alerts

A full-stack MERN news platform with JWT authentication, personalized news preferences, real-time news updates, and automated email alerts using News API, Nodemailer, and MongoDB.

---

# 🚀 Live Demo

### Frontend
https://mern-news-alert-app.vercel.app/

### Backend
https://mern-news-alert-app.onrender.com/

---

# ✨ Features

- 🔐 JWT Authentication
- 👤 User Registration & Login
- 📰 Real-Time News Dashboard
- 🎯 Personalized News Preferences
- 📧 Automated Email News Alerts
- 🌐 Multiple News Categories
- 📱 Fully Responsive UI
- ⚡ Fast MERN Stack Performance
- ☁️ Deployed on Vercel & Render

# ⚙️ Environment Variables

Create a `.env` file inside the `server` folder:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
NEWS_API_KEY=your_news_api_key
EMAIL_USER=your_email
EMAIL_PASS=your_email_app_password
```

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Arpit-Kahale/mern-news-alert-app.git
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```
